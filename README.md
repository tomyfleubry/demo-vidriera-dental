# Clínica Dental Serena

Vidriera ficticia de odontología integral creada por Nexvia IA.

Sitio: https://tomyfleubry.github.io/demo-vidriera-dental/

HTML estático, fotos Pexels locales en WebP, acordeones de tratamientos con consulta específica,
comparador accesible por teclado, recorrido vertical con presupuesto, equipo y lista de control.
El comparador es una simulación digital de una misma foto de stock;
no muestra un caso clínico ni promete resultados.

Marca, personas y datos son ficticios. WhatsApp es un número placeholder.
No hay formularios, cobros ni integración de pagos. Las imágenes son
ilustrativas: fuentes y sistema visual en [DESIGN.md](DESIGN.md).

GitHub Pages: main / raíz. Meta noindex, nofollow y robots.txt.
